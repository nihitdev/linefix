# Changelog

All notable changes to this project are documented here.

## v0.1.0

- Convert files between LF and CRLF line endings in place.
- Detect LF, CRLF, mixed, and newline-free text files.
- Preserve permissions, trailing-newline state, and already-normalized files.
- Reject likely binary files.
- Provide cross-platform release archives and checksum-verifying installers.
