Fix the bytes.

01

Safe by default

Likely binary files are rejected before a write. CRLF is normalized before conversion, avoiding accidental doubled carriage returns.

02

Respectful edits

Permissions and trailing-newline state stay intact. Already-normalized files are left untouched.

03

Built to travel

One dependency-free executable with official AMD64 and ARM64 builds for Linux, macOS, and Windows.

Get started

Install in one command.

Installers detect your platform and architecture, then verify the release checksum before installation.

Linux & macOSsh
curl -fsSL https://raw.githubusercontent.com/
nihitdev/linefix/main/install.sh | sh

Installs to ~/.local/bin by default. Supports Intel and Apple Silicon Macs.

WindowsPowerShell
irm https://raw.githubusercontent.com/nihitdev/
linefix/main/install.ps1 | iex

Installs per-user and updates your user PATH without requiring Administrator privileges.

Three commands

Exactly what you need.

linefix lf <file>convert

Convert CRLF endings to LF.

linefix crlf <file>convert

Normalize and convert LF endings to CRLF.

linefix check <file>inspect

Report LF, CRLF, Mixed, or No line endings.

No config. No runtime. No surprises.

Make every newline intentional.
